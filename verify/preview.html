请设计一个插件以美化现版本的 DSH 界面 UI

设计方案：令牌重塑 + 结构精修

插件不改动宿主组件，而是通过 ctx.theme.overrideTokens() 把一套新的设计令牌叠到当前主题之上。

  • 品牌位从近黑白切到强调色，界面第一次有了识别色
  • 表面分级 + 冷调阴影，浅色下不再是一片纯白
  • 圆角、行高、字距统一上调，长时间阅读更省力
TypeScript复制
export function apply(ctx: ClientContext) {
  const controller = createController({ theme: ctx.theme })
  ctx.effect(() => controller.mount(), 'ui-beautify: 外观层')
}
